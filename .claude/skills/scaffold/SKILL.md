---
name: scaffold
description: Use when generating new files for components, tables, models, or routes.
---

Generate files with pnpm sscg.

## Common Rules

- You may delete unneeded code/files from the generated output
- Don't delete code/files generated by db-model / model, even if unused
  - They are the shared foundation for all models

## component

```bash
pnpm sscg component -r <name> -o app/components/<name>
```

## table

```bash
pnpm sscg table -r <name> -o app/adapters/db/tables
```

After generating, register the new table in `app/adapters/db/database.ts`.

## model

```bash
# Model backed by the database
pnpm sscg db-model -r <name> -o app/models/<name>

# Other data sources
pnpm sscg model -r <name> -o app/models/<name>
```

## route

```bash
pnpm sscg route -r <name> -o app/routes/<path>
```
